# ProjectManager

## Objetivo

Construir um sistema para acompanhar o ciclo de vida de projetos e organizar o
trabalho em cards distribuídos por sprints. Referência externas servem
como inspiração para padrões gerais de organização visual do trabalho — como
quadros, status, layout e demais componentes.

## Premissas do MVP

- O projeto é o espaço principal para agrupar o trabalho.
- Cada projeto pode ter um quadro com cards organizados em sprints.
- O ciclo de vida do projeto e o andamento dos cards devem ser visíveis.
